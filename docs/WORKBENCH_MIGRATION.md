# v0.9.1 工作台迁移基线

当前源码已进入 v0.9.2 第二轮 UI 优化，本地分支为 `codex/v0.9.2-ui-polish`，尚未发布。本文保留 v0.9.1 的工作台迁移契约与历史证据，继续约束本轮修改；此前未完成的原生验收不因版本调整而自动通过。

## 设计原型（独立示例入口）

```powershell
.\.venv\Scripts\python.exe main.py --workbench-prototype
```

使用 6 个内存示例文件，不读取真实设置或凭据、不扫描路径、不调用 Bandizip、不写文件。修改顶部路径只改变示例摘要。可以编辑分类和文件命名规则，切换层并修改配置，新增/复制/删除层，查看逐层输入输出，选中成员定位来源，切换深浅色或查看摘要。

右侧常驻「当前步骤」与「文件名实时预览」两个标签。进入原文件命名时默认显示文件名对照，其他步骤也可随时查看；每个步骤保留本次选择的预览标签。默认突出原文件名与命名后两列，可按分类筛选并通过「更多信息」显示分类目录、所属最外层归档，长名称可横向滚动并悬停查看完整文本。筛选只影响视图，不改变任务配置；刷新时保留仍存在的分类选择。输入规则时无需退出单元格即可刷新；归档模板错误时保留有效文件名对照，归档列显示待修正；文件命名自身错误时清空对照并提示。有效对照的计数显示在工具栏，错误及密码警告仍显示在预览顶部。流程导航保留蓝色选中反馈和键盘操作，取消系统黑色内框。

筛选工具栏四周留白 8px，分类、更多信息和计数垂直居中。预览树与文件名表使用柔和选中底色及清晰文字，获得/失去焦点不改变文字布局；树的展开箭头继续显示并可操作。横/纵滚动条采用 10px 细轨道与圆角滑块，保留拖动、滚轮和键盘范围；默认双列模式隐藏无意义的横向滚动，展开更多信息后按需出现。

路径在宽窗口并排、窄窗口上下排列；原文件规则表随条数伸缩，超过八行后在表内滚动，说明与操作保持相邻。窄窗口初次改为上下分栏时给预览约六成空间，之后同方向缩放保留用户拖动比例。字体和控件对比度统一，按钮按下及输入焦点均有反馈；导航、键盘和实时预览不加入切换动画。设计参考用户指定目录的 emil-design-series / emil-design-eng 原则，继续使用 PySide6。

侧栏标题、次要摘要、层号与状态分开显示。只有压缩层在右侧显示轻立体层号（01、02；100 以上完整显示），最外层独立标记，组数在悬停说明和步骤预览中查看。数字由 0–9 矢量字形及主题/DPI 缓存绘制，不附带额外位图资源。导航保留鼠标/键盘行为和完整无障碍名称。

每个数字字形按 0–9 中的最大宽度居中放入等宽单元，窄字形“1”和其他数字的中心及步距一致。下拉框使用单层平面细边框和统一箭头绘制，去除系统的凸起/阴影边缘；交互和弹出列表仍由 Qt 管理，鼠标/键盘焦点规则不变。

分类筛选与压缩格式下拉框鼠标选择后维持普通边框；Tab/Shift+Tab 进入时用柔和底色提示，键盘选择或关闭列表后保留提示，焦点离开后消除，不通过强制失焦处理。弹出列表仍有正常的选中高亮。共享 LayerRow 的 format_combo_factory 为可选参数，默认仍为原 QComboBox，仅原型注入新组件；引擎和断点字段不变。

首次启动默认 1100×800（刚好进入左右布局） 并按屏幕限制；小于 1100px 时编辑和预览上下排列。最低支持 640×600。归档名称直接展示，密码设置按需展开。示例入口禁用真实执行与恢复；正式入口 main.py 已接入目录选择、完整设置、排序、执行及取消。预览为只读示例计划，不预测卷数和压缩大小。

## 正式迁移的接口边界

- 工作区状态成为配置唯一来源；每个层的原始文本、密码确认、展开及显示状态独立保存。节点用会话内稳定 ID，序号仅显示，不替换归档/断点身份。
- 控件编辑状态，统一适配器导出原引擎配置。移除隐藏旧控件的配置控制权；不修改 Layer 持久化字段或旧断点版本。
- 预览只读，复用 planning/nesting；未确认密码不阻断结构预览，但阻止执行。结构无效时清空结果并提示，不将旧结果冒充当前结果。
- 真实目录扫描在后台执行，180ms 防抖并携带修订编号，主线程应用匹配结果。示例入口仍为内存模型，正式入口启用后台扫描。
- 控制器负责确认、固定快照、启动/取消/恢复和生命周期；执行时编辑只读，流程导航可查看。扫描/预览服务不得执行文件操作。
